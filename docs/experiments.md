# 실험 기록

모든 버전의 변경점, 교차 검증(CV) 점수, 리더보드(LB) 점수, 채택·기각 이유를 정리한 문서입니다.
새 실험을 하면 표 맨 아래에 한 줄씩 추가합니다.

## 공통 규칙

- **지표**: log(SalePrice)의 RMSE. 대회 평가 지표와 같습니다.
- **CV**: `KFold(5, shuffle=True, random_state=42)`로 나눈 OOF 예측의 RMSE입니다. 학습 데이터는 이상치 2채(Id 524, 1299)를 뺀 1,458채입니다.
  - OOF(Out-of-Fold) 예측: 각 집을 그 집이 빠진 fold로 학습한 모델로 예측한 값입니다. train 전체에 대해 "처음 보는 집" 기준 예측을 얻을 수 있습니다.
- **피처 비교**: `RepeatedKFold(5×3)`로 15번 채점해서 짝지어 비교합니다. 평균과 함께 "15번 중 몇 번 좋아졌는지"를 같이 봅니다.
- **스택(stack)**: OOF 예측을 입력으로 받는 메타 모델(양수 가중치 선형회귀)이 모델별 가중치를 학습하는 방식입니다. 메타 모델도 바깥 KFold로 다시 채점하고, 분할을 6~10가지로 바꿔 평균을 냅니다.
- **블렌드(blend)**: 학습 없이 모델 예측을 같은 비중으로 단순 평균하는 방식입니다.
- **Id 2550 규칙**은 Step 3 이후 모든 제출에 들어 있습니다.
- CV 칸이 `–`이면 test에만 적용되는 규칙이라 CV로 잴 수 없다는 뜻입니다.

### v4 — 하이브리드
- 구조 모델(원가법: 땅값 + 건물 면적 × 단가 × 품질 × 감가로 가격을 짜 맞춘 수식 모델)이 먼저 가격을 예측하고, Lasso는 구조 모델의 잔차(실제 − 예측)만 학습합니다.
- 오차 상관(OOF 기준): 하이브리드와 Lasso_w 0.92, XGBoost 0.84, SVR 0.87, 구조v4 0.95
- 바깥 분할 seed 1/2/3: Lasso_w 0.1082/0.1093/0.1080 → 하이브리드 0.1059/0.1071/0.1067
- 주의했던 점: test 예측이 Lasso와 10% 넘게 다른 집이 66채였고, 그중 상위권이 IDOTRR 동네에 몰려 있었습니다. 구조 모델이 IDOTRR의 땅값과 건축비를 맞바꿔 추정하는 약점을 물려받은 것입니다. 이 문제가 v4.1의 출발점입니다.

## 정리: 리더보드까지 넘어온 개선의 종류

1. **데이터를 보고 만든 규칙**: Id 2550 규칙(−0.0055), 코너 보정(−0.0001)
2. **거의 모든 집에 적용되는 피처 정리**: v2 (Step 4 최고 0.11660 → 0.11535)
3. **다르게 틀리는 모델을 적당한 비중으로 섞기**: Lasso + XGBoost, + SVR, v4 하이브리드 블렌드, v5 4개 블렌드(v4와 동점)

넘어오지 않은 것:
- 스택에서 구조 모델 계열이 33%를 넘는 가중치를 받은 조합(v3.1 stack 0.39, v4 stack 0.54): 같은 모델의 단순 평균보다 LB가 나빴습니다. 단순 평균인 v5(구조 계열 0.50)는 최고 점수와 같았습니다.
- train의 일부 구간에 맞춘 항목(제곱항, IDOTRR 제약)

남은 오차는 상업지역, 금융위기 시기(2008~2009)의 Partial 거래, 비정상 거래처럼 가격이 정해진 이유가 79개 피처에 없는 집들에 몰려 있습니다.
